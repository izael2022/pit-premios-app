# PIT PRÊMIOS APP

Aplicativo web/PWA em construção para a plataforma PIT PRÊMIOS.

## Estado atual

- Protótipo visual em React + Vite.
- Navegação inicial: Início, Missões, Convites, Carteira e Perfil.
- Conteúdo demonstrativo apenas; ainda não conectado ao servidor.
- **Não altera nem acessa o banco de dados de produção.**

## Desenvolvimento

```bash
npm install
npm run dev
```

Próximas etapas: autenticação segura e integração com API existente, mantendo as regras do servidor como fonte de verdade.
